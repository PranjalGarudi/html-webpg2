# 🚚 Move It – Moving Services Website

**Move It** is a modern, responsive **landing page website** built using **HTML5, Bootstrap 5, and minimal custom CSS**. The project represents a startup moving company focused on providing a stress-free, joyful moving experience across the US.

---

## 🎯 Project Purpose

The main goal of this project is to:

* Practice building a real-world website using **Bootstrap 5**
* Learn responsive layouts with minimal custom CSS
* Design a clean, professional landing page for a service-based business
* Understand how to structure UI sections using Bootstrap components

---

## ✨ Key Features

* 📱 Fully responsive design (mobile, tablet, desktop)
* 🧭 Bootstrap navigation bar with dropdown menu
* 🎯 Hero section with call-to-action buttons
* 💼 Feature section highlighting services
* 🖼️ Image carousel for visual storytelling
* 📨 Newsletter subscription form
* 🦶 Multi-column footer layout

---

## 🛠️ Tech Stack

* **HTML5** – Structure and content
* **Bootstrap 5** – Layout, components, responsiveness
* **CSS3** – Minor custom styling
* **Bootstrap Icons / SVGs** – Visual elements

> ⚠️ No backend or JavaScript logic written manually — Bootstrap JS used via CDN.
